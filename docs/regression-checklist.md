# Quickbar 手工回归清单

发版或大改前：先跑 `npm run test:all`，再按本清单点验 UI（自动化覆盖不到热键/窗口行为）。

环境：Windows，项目在 `C:\dev\quickbar`，热键默认 `Ctrl+Space`。

## 启动与热键

- [ ] 托盘图标存在；`Ctrl+Space` 可唤起主窗
- [ ] 失焦后主窗隐藏；再次热键可唤起
- [ ] 空查询显示启动页（最近使用 / 已固定 / 市场精选）

## 会话保留

- [ ] 打开 JSON 工具 → 失焦隐藏 → 再热键 → **仍停在 JSON**，不回首页
- [ ] 打开应用市场 → 失焦隐藏 → 再热键 → 仍在市场（或可接受的当前页）

## JSON 工具

- [ ] 树形视图：节点可折叠 / 展开；「全部折叠」「全部展开」有效
- [ ] 文本 / 树形切换正常；非法 JSON 时可回到文本修改
- [ ] 过滤栏 `this |`：点示例芯片（如 `.key.subkey`、`.items.map`）结果正确
- [ ] Esc / 清除可取消过滤；Enter / 应用结果可写回

## 分离窗口

- [ ] 插件页「分离窗口」或 `Ctrl+D` 打开独立窗（带系统标题栏）
- [ ] 可连续分离 **多个** 窗口（含同一 JSON 工具多实例）
- [ ] 独立窗「置顶」开关有效；最小化 / 关闭正常
- [ ] 分离后主窗回到启动页；独立窗失焦不随主窗一起消失

## 市场与最近使用

- [ ] 应用市场可看到 catalog 项；安装 `json-format` 成功
- [ ] 安装后可从搜索或启动页打开插件
- [ ] 「最近使用」点 JSON 类条目打开插件，而不是误进市场

## 多显示器（有双屏时）

- [ ] 主窗打开时，鼠标在另一屏按热键：窗口跟到当前屏，而不是直接隐藏
